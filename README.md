# Register Form App

A simple registration form built with Flutter as a learning project.

## Features

- Full name validation
- Phone number validation (11 digits)
- Email input field
- Life story input with a 100-character limit
- Password and confirm password fields
- Show and hide passwords
- Clear name and phone number fields
- Form validation before submission

## What I Learned

- Using `TextFormField` and `TextEditingController`
- Validating user input with `validator`
- Using `GlobalKey<FormState>` to validate a form
- Using `TextInputFormatter` to control input
- Showing and hiding passwords with `setState()`
- Managing controllers with `dispose()`
- Handling form submission

## Technologies

- Flutter
- Dart
- Material Design

This project helped me practice Flutter forms, user input, and validation.
